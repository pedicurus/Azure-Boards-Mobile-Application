# Azure Boards Android Releases

This directory contains pre-built APK packages for the **Azure Boards** Android app.

## 📦 Latest Release: `v3.0`

- **Filename**: `azure-boards-v3.0.apk`
- **Build Type**: Signed Android Application Package (APK)
- **Min SDK**: Android 7.0 (API 24)
- **Target SDK**: Android 15 (API 36)

### How to Install on Android Devices

1. Download `azure-boards-v3.0.apk` onto your Android phone or tablet.
2. Tap the downloaded file in your browser or file manager.
3. If prompted, grant permission to "Install Unknown Apps" for your file manager or browser.
4. Tap **Install** and open Azure Boards.

### How to Attach to GitHub Releases

When publishing a Release on GitHub:
1. Go to your GitHub repository and navigate to **Releases** > **Draft a new release**.
2. Set the tag (e.g. `v3.0`).
3. Drag and drop `releases/azure-boards-v3.0.apk` into the **Attach binaries by dropping them here or selecting them** box.
4. Click **Publish release**.
